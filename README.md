## Questions

### 1. Even or Odd

The `even_or_odd()` function checks whether a given number is divisible by 2.

* If the number is divisible by 2, it returns `"Even"`.
* Otherwise, it returns `"Odd"`.

The solution uses an `if-else` statement and the modulo (`%`) operator.

### 2. Sum of a List

The `add_all()` function calculates the total sum of all numbers in a list.

The solution starts with a total of `0` and uses a `for` loop to add each number to the total. The final total is then returned.
